# 📊 Data Visualization (DataViz)

## 🎯 Objetivo
- Entender o dataset  
- Encontrar padrões  
- Ajudar na tomada de decisão  

---

## 💡 Motivação
- Um gráfico responde uma pergunta  
- Um gráfico mostra algo com clareza  
- Vários gráficos = várias respostas  

### 👉 Exemplos
- Tendência mensal → gráfico de barras  
- Valor mais comum → histograma  
- Valores extremos → boxplot  
- Relação entre variáveis → scatter plot  

---

## 📈 Tipos de Gráficos

### Gráfico de Barras
- Comparar categorias  
- Ex: vendas por mês  

### Histograma
- Ver distribuição dos dados  
- Ex: frequência de preços  

### Boxplot
- Identificar outliers (valores fora da curva)  
- Mostra mediana e dispersão  

### Scatter Plot (Gráfico de Dispersão)
- Relação entre duas variáveis  
- Ex: distância vs preço  
- Pode usar regressão linear  

### Heatmap
- Visualizar correlação entre variáveis  

---

## 📊 Dashboard
- Conjunto de gráficos  
- Cada gráfico responde uma pergunta  
- Deve ser simples e objetivo  

---

## 🔍 Análise de Dados

### Análise Exploratória (EDA)
- Primeira etapa  
- Entender o comportamento dos dados  
- Encontrar padrões e outliers  

### Padrões
- Tendências  
- Repetições  
- Relações  

---

## 📉 Estatística Básica
- Média → valor médio (soma ÷ quantidade)  
- Mediana → valor do meio (dados ordenados)  
- Média anual → média dos 12 meses  

---

## ⚠️ Conceitos Importantes

### Outliers
- Valores muito fora do padrão  

### Correlação
- Positiva → variáveis aumentam juntas  
- Negativa → uma sobe, outra desce  

### Correlação Espúria
- Parece relação, mas não existe  

### Causalidade
- Uma variável causa a outra  

---

## 🤖 IA + Análise de Dados
- IA pode analisar seu `.csv`  
- Sugerir gráficos ideais  
- Detectar dados faltantes ou inconsistentes  

---

## 🛠 Ferramentas
- Matplotlib → criar gráficos  
- Seaborn → gráficos mais bonitos  
- Jupyter Notebook → análise de dados  
- Docker → ambiente isolado
