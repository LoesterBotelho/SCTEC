JavaScript - Variáveis e Arrays

1. var

var é a forma antiga de criar variável.

var nome = "João";

2. let

let permite alterar valor.

let idade = 20; idade = 30;

3. const

const cria valor fixo.

const pais = "Brasil";

4. String

Texto em JavaScript.

let texto = "Olá Mundo";

5. Number

Números.

let numero = 100;

6. Boolean

true ou false.

let logado = true;

7. null

Valor vazio.

let valor = null;

8. undefined

Variável sem valor.

let teste;

9. Array

Lista simples.

let frutas = [ "Maçã", "Banana", "Uva" ];

10. push()

Adicionar item no array.

frutas.push("Laranja");

11. pop()

Remove último item.

frutas.pop();

12. length

Quantidade de itens.

frutas.length

13. forEach()

Percorre array.

frutas.forEach(function(fruta){ console.log(fruta); });

14. Array Bidimensional

Array dentro de array.

let alunos = [ ["João",20], ["Maria",25], ["Pedro",30] ];

15. Objeto

Objeto guarda propriedades.

let pessoa = { nome:"João", idade:20, cidade:"Florianópolis" };

16. Array de Objetos

Muito usado em sistemas.

let usuarios = [ { nome:"João", idade:20 }, { nome:"Maria", idade:25 } ];
