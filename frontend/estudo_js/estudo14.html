JavaScript Básico Completo

1. if else if else

if verifica condição.

Quando existe muitas condições, normalmente switch case fica melhor.

let nota = 7; if(nota >= 9){ console.log("Excelente"); }else if(nota >= 7){ console.log("Aprovado"); }else{ console.log("Reprovado"); }

2. switch case

switch é bom para várias opções.

switch(cor){ case "azul": break; case "verde": break; default: break; }

3. for e i++

i++ adiciona +1.

for(let i = 0; i < 5; i++){ }

4. while

let i = 0; while(i < 5){ i++; }

5. do while

Executa ao menos 1 vez.

do{ }while();

6. texto += item

+= adiciona texto.

texto += item;

7. break

break para o laço.

break;

8. continue

continue pula item.

continue;
