JavaScript - Todos Tipos de Listas

1. Lista de Strings

Lista simples de textos.

let carros = [ "BMW", "Audi", "Ferrari" ];

2. Lista de Números

Lista de números.

let numeros = [ 10, 20, 30 ];

3. Lista Boolean

Lista true e false.

let status = [ true, false, true ];

4. Lista Mista

Tipos diferentes.

let dados = [ "João", 20, true ];

5. Lista de Objetos

Muito usada em sistemas.

let usuarios = [ { nome:"João", idade:20 } ];

6. Lista Bidimensional

Array dentro de array.

let matriz = [ ["João",20], ["Maria",25] ];

7. push()

Adicionar item.

carros.push("Honda");

8. pop()

Remove último item.

carros.pop();

9. shift()

Remove primeiro item.

carros.shift();

10. unshift()

Adicionar no começo.

carros.unshift("Tesla");

11. splice()

Adicionar ou remover.

carros.splice(1,1);

12. slice()

Copiar parte do array.

carros.slice(0,2);

13. forEach()

Percorrer lista.

carros.forEach()

14. map()

Criar novo array.

numeros.map()

15. filter()

Filtrar lista.

numeros.filter()

16. find()

Buscar item.

numeros.find()

17. length

Quantidade de itens.

carros.length
