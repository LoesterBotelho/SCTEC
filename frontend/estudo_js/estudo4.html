Exercícios de Arrays

1 e 2. Criar Array e Exibir

let frutas = ["Maçã", "Banana", "Laranja", "Uva", "Manga"];
console.log(frutas);

3. Acessar Terceiro Item

console.log(frutas[2]);

4. Alterar Segundo Item

frutas[1] = "Morango";
console.log(frutas);

5. Adicionar duas frutas (.push)

frutas.push("Abacaxi", "Kiwi");
console.log(frutas);
