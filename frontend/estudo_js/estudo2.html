JavaScript - Arrays e forEach

1. Lista de Nomes

Um array pode guardar vários nomes.

const nomes = [ "João", "Maria", "Pedro" ];

2. Lista de Frutas

Arrays são muito usados para listas.

let frutas = [ "Maçã", "Banana", "Laranja" ];

3. Lista de Comidas

Você pode adicionar itens usando push().

let comidas = [ "Pizza", "Hambúrguer" ]; comidas.push("Lasanha");

4. Lista de Compras

Exemplo simples de mercado.

const compras = [ "Arroz", "Feijão", "Leite", "Café" ];

5. const

const cria um valor fixo.

Você NÃO pode trocar o valor.

const cidade = "Florianópolis";

6. let

let permite alterar o valor.

let idade = 20; idade = 30;

7. forEach

forEach percorre todos os itens do array.

const frutas = [ "Maçã", "Banana", "Laranja" ]; frutas.forEach(function(fruta){ console.log(fruta); });

8. Array Bidimensional

Array dentro de array.

Muito usado em tabelas.

const alunos = [ ["João",20], ["Maria",25], ["Pedro",30] ];
