JavaScript Arrays - Guia Completo

1. Criando Array

Array é uma lista de dados.

let frutas = [ "Maçã", "Banana", "Laranja" ];

2. Pegando posição do Array

Arrays começam na posição ZERO.

frutas[0] frutas[1] frutas[2]

3. push() - Adicionar item

push adiciona item no FINAL do array.

frutas.push("Uva");

4. pop() - Remover último item

pop remove o ÚLTIMO item.

frutas.pop();

5. shift() - Remove primeiro

shift remove o PRIMEIRO item.

frutas.shift();

6. unshift() - Adicionar no começo

unshift adiciona no início.

frutas.unshift("Morango");

7. length - Quantidade

length mostra quantos itens existem.

frutas.length

8. forEach()

Percorre todos os itens.

frutas.forEach(function(fruta){ console.log(fruta); });

9. includes()

Verifica se existe item.

frutas.includes("Banana")

10. indexOf()

Mostra posição do item.

frutas.indexOf("Banana")

11. splice()

Remove item específico.

frutas.splice(1,1);

12. Array Bidimensional

Array dentro de array.

let alunos = [ ["João",20], ["Maria",25] ];

13. const e let

const = valor fixo

let = valor que pode mudar

const pais = "Brasil"; let idade = 20; idade = 30;
