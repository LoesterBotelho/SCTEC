JavaScript - Arrays e Variáveis

1. var

A palavra var é usada para criar variáveis.

Ela é mais antiga no JavaScript.

Hoje usamos mais let e const.

// VAR = variável antiga var nome = "João"; console.log(nome);

2. let

let cria variáveis modernas.

Você pode mudar o valor depois.

// LET = variável moderna let idade = 20; idade = 25; console.log(idade);

3. const

const cria constantes.

O valor NÃO pode mudar.

// CONST = valor fixo const pais = "Brasil"; console.log(pais);

4. Array

Array é uma lista de valores.

Você pode guardar:

  • nomes
  • idades
  • números
  • produtos
// ARRAY = lista let frutas = [ "Maçã", "Banana", "Laranja" ]; console.log(frutas);

5. Posição do Array

Cada item possui uma posição.

A contagem começa no ZERO.

let frutas = [ "Maçã", "Banana", "Laranja" ]; // posição 0 console.log(frutas[0]); // posição 1 console.log(frutas[1]);

6. Array Bidimensional

É um array dentro de outro array.

Parece uma tabela.

let alunos = [ ["João", 20], ["Maria", 25], ["Pedro", 30] ]; console.log(alunos);

7. Percorrendo Array

Usamos for para repetir.

let numeros = [10,20,30]; for(let i = 0; i < numeros.length; i++){ console.log(numeros[i]); }
