JavaScript - Classes, Objetos e JSON

1. Classe

Classe é um modelo para criar objetos.

class Carro{ constructor(marca,modelo,ano){ this.marca = marca; this.modelo = modelo; this.ano = ano; } }

2. Objeto JavaScript

Objeto guarda propriedades.

let carro = { marca:"Toyota", modelo:"Corolla", ano:2025 };

3. Array de Objetos

Muito usado em sistemas.

let carros = [ { marca:"Toyota", modelo:"Corolla", ano:2025 }, { marca:"Honda", modelo:"Civic", ano:2024 } ];

4. JSON

JSON é formato de dados.

let json = ` { "marca":"Toyota", "modelo":"Corolla", "ano":2025 } `;

5. JSON.parse()

Transforma JSON em objeto JavaScript.

JSON.parse(json);

6. JSON.stringify()

Transforma objeto em JSON.

JSON.stringify(objeto);

7. constructor

constructor recebe valores.

constructor(nome){ this.nome = nome; }

8. this

this representa o objeto atual.

this.nome

9. Método

Método é função dentro da classe.

ligar(){ return "Carro ligado"; }
