JavaScript Básico - Loops e Condições

1. while

while repete enquanto a condição for verdadeira.

let i = 1; while(i <= 5){ console.log(i); i++; }

2. i++

i++ adiciona +1 na variável.

let i = 0; i++;

3. texto +=

+= adiciona mais texto.

texto += "Novo texto";

4. do while

Executa pelo menos uma vez.

let i = 1; do{ console.log(i); i++; }while(i <= 5);

5. for

for é usado para repetição.

for(let i=1; i<=5; i++){ console.log(i); }

6. if e else

Tomada de decisão.

if(idade >= 18){ console.log("Maior"); }else{ console.log("Menor"); }

7. else if

Verifica várias condições.

if(nota >= 7){ console.log("Aprovado"); }else if(nota >=5){ console.log("Recuperação"); }else{ console.log("Reprovado"); }

8. switch

switch compara valores.

switch(cor){ case "azul": console.log("Azul"); break; case "verde": console.log("Verde"); break; }

9. Operadores Matemáticos

+ - * / %

10. Boolean

true ou false

let logado = true;

11. Arrays

let frutas = [ "Maçã", "Banana", "Uva" ];

12. forEach

frutas.forEach(function(fruta){ console.log(fruta); });
